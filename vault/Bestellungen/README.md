# Bestellungen

Je Bestellung eine Notiz `YYYY-MM-DD-<lieferant>.md`. Das ist das Rohmaterial für die JLCPCB-Case-Study — also vollständig und mit Fotos.

## Vorlage
```
# YYYY-MM-DD — <Lieferant>

**Zweck:** …  **Bestellnummer:** …  **Status:** bestellt / unterwegs / da

| Pos | Artikel | Stück | Einzelpreis | Summe | Link |
|---|---|---|---|---|---|

**Gesamt:** … € inkl. Versand · **Lieferzeit:** … Tage · **Tracking:** …

## Notizen
- Was war anders als erwartet, was fehlt, was ist kaputt angekommen

## Fotos
![](fotos/YYYY-MM-DD-<lieferant>-01.jpg)   (skaliert, ≤ 1 MB)
```

**Sponsoring:** Bei JLCPCB-Bestellungen Leon erinnern, den JLCPCB-Kontakt zu informieren (Bestellnummer + kurze Projektbeschreibung + Link zum Repo).
