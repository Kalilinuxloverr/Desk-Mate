# Bauanleitung

Noch gibt es nichts zu bauen — Desk-Mate ist in der Design-Phase. Diese Anleitung wächst mit jedem abgeschlossenen Schritt und soll am Ende einen kompletten Nachbau erlauben, ohne das Repo durchwühlen zu müssen.

## Geplante Kapitel

| Nr | Kapitel | Status |
|---|---|---|
| 00 | Überblick, Werkzeug, Teile besorgen ([Stückliste](../../hardware/bom.md)) | Entwurf folgt mit der Bestellung |
| 01 | Platinen bestellen (Gerber, JLCPCB) | nach KiCad |
| 02 | Löten: Mainboard (alles Through-Hole) | nach Lieferung |
| 03 | Löten: Frontpanel (Fader, Tasten, Encoder) | nach Lieferung |
| 04 | 3D-Druck: Base, Bauch, Kopf, Visier | nach Gehäuse-Design |
| 05 | Zusammenbau + Verkabelung | — |
| 06 | Firmware flashen (arduino-cli) | — |
| 07 | Mac-Agent + Handy-App einrichten | — |
| 08 | Claude-Code-Hooks aktivieren | — |
